# Traffic Light Controller using Verilog HDL

This project implements a simple traffic light controller using Verilog HDL and FSM.

## Description

The controller operates three traffic signals: Red, Green and Yellow. The signals change according to the designed state sequence.

## Tools Used

- Verilog HDL
- Xilinx Vivado

## Files

- traffic_light_controller.v - Main Verilog design
- traffic_light_controller_tb.v - Testbench

## Working

The design uses a finite state machine to control the traffic light sequence.

Red → Green → Yellow → Red
